Provenance of the changes: where each idea came from

One row for every method or feature in dMapper that can move the trajectory or the point cloud, in date order. Each row names where the idea came from (HDMapping, a paper, standard practice, a session with Claude, the Codex agent, the user), taken from the change folders, the region knowledge files, the code-review tracker and the commit messages. Written 2026-11-25 from the files only.

Terms used here: window, NDT, motion model, term, prior, gyro bias, velocity, acceleration offset, degeneracy, bend, hand-off, AHRS, lever arm, segment, loop closure, pose graph, weak run, consistency pass, settings, capture and replay, baseline. All basic terms: the guide's Fundamentals.

What is on today

  • settings/l2-vertical.toml (Unitree L2): time-scaled rotation prior, gyro bias estimation, imu_always_on, degenerate projection 0.1/0.2, loop closure with gating, path rule, information-weighted edges and cross-floor edges, consistency pass (10 passes), max_prior_velocity_mps 5, AHRS gain 0.05.
  • settings/livox-vertical.toml (Livox Mid-360S): the same base, plus measured gyro noise (k 1), Huber 3 with NDT and IMU-position information scales 0.1, exact NDT cell statistics, degenerate projection 0.02/0.04, offset random walk 0.01, AHRS gain 0, gyro scale z 1.004, imu_edges_follow_state, the blind-stretch rule, the match check and the fine-time placement (since 2026-11-25, 89e8047); consistency off.
  • Still HDMapping's in today's code: the NDT point term and its cell map (update_rgd, the bucket statistics used by default), the motion-model edges with the generated observation_equations Jacobians, the scan-to-map window optimization's structure, the consistency pass (Consistency), the value types and pose conversions (structures.h, transformations.h, ndt_types.h, point_placement.h, unchanged), the Fusion AHRS use, and decimation. All have since been split, re-weighted and wrapped; the record does not mark line by line what is unchanged.

Where the record disagrees with itself

  • Loop closure's origin. dMapper's automatic loop closure was written 2026-10-01 (00b8962, Claude Opus); HDMapping's core had pose-graph loop-closure files, and the record does not say whether any was used.
  • imu_edges_follow_state date. Committed 2026-11-24 (07c0ae4); the settings comment says "on since 2026-11-25".
  • Fine-time placement. Shipped on the user's look at the Livox 4 clouds (task 4.6, 89e8047), while the log measures on that recording are equal within a few dozen returns: the evidence for it there is the user's eye, not a number.
  • Shipped despite a missed gate. imu_always_on (6.1 m between builds against a 0.31 m gate), loop-closure C* (stair guard, 1.77 > 1.7°), gyro scale (repeats 1.16–3.07 m against 0.85 m). Each was the user's decision on the map.
  • Same value, two verdicts. Exact NDT statistics and offset random walk 0.01 were rejected for the L2 on 44 and are on for the Livox.
  • Open task lists for shipped values. gyro-scale-correction 3.x, livox-measured-gyro-noise 2.x, robust-loop-closure 5.x are unchecked although the values ship. The weak-runs change shipped ahrs_gain 0 and gyro scale 1.004, "not listed to the user; reported to them".
  • Livox 3 verdicts. "crisp" (11-13), "horrible" (11-15), "the best so far" (run G, 11-16): different settings each time.
